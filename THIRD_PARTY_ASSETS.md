# Third-party pixel assets

The game bundles a small number of permissively licensed pixel-art props. They are copied into the project so the game does not depend on GitHub at runtime.

## Dungeon Crawl Stone Soup / RLTiles

- Source: https://github.com/crawl/crawl
- Pinned commit: `da980d1564a996e793f0bb667d9db36ed7c17803`
- Files used: `crawl-ref/source/rltiles/item/ring/gold_blue.png`, `gold_green.png`, `diamond.png`
- License: the repository's `crawl-ref/source/rltiles/license.txt` identifies the relevant RLTiles graphics as public domain.

## Pixel Agents

## Kenney asset library

- Source mirror: https://github.com/shorepine/kenney
- Pinned commit: `3694c6879e487c108f55677be7dd2ca75b07cc3b`
- Files used: `keyYellow.png`, `film.png`, `2d/Block Pack/Retina/market_stallBlue.png`

## Kenney Fish Pack 2.0

- Source repository: https://github.com/Tiddybub/2d-assets/tree/main/characters/fish-pack
- Original source: https://kenney.nl/assets/fish-pack
- Files used: five fish sprites, three bubble sprites, and three seaweed sprites from `PNG/Double/`
- License: CC0 1.0 / public domain. The bundled `License.txt` permits personal, educational, and commercial use without required attribution.

## Murmur boids reference

- Source: https://github.com/ctkrug/murmur
- Technique referenced: Canvas flocking built from separation, alignment, and cohesion forces, adapted here for fish that scatter around Jenny and regroup afterward.
- License: MIT.

## Kenney urban scene references

- Source repository: https://github.com/GeorgeQLe/assets-2d-city
- Packs referenced: Kenney Retro Urban Kit and Kenney RPG Urban Pack.
- Use in this project: street proportions, storefront modules, pavement, windows, signs, benches, and urban lighting were used as composition references; the final Seoul street is redrawn in the game's own pixel-canvas style.
- License: CC0 1.0 / public domain.

## Twemoji shape references

- Source: https://github.com/twitter/twemoji
- Graphics referenced: soft ice cream silhouette. The in-game long ice cream is newly drawn in the project's pixel-canvas style.
- Graphics license: CC BY 4.0, Copyright Twitter, Inc. and other contributors.

## Hello Kitty silhouette icon
