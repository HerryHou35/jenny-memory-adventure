# Version 19 对照 PRD 的打磨记录

## 已修正的体验缺口

- 八张胶片集齐后原本停在不可交互的放映室；新增可启动的蒙太奇、实际章节成果、真实合照收尾及生日视频接入。
- 原本只能清空整个进度；新增胶片墙单章重玩、稳定操作节点恢复、存档损坏兜底与清空确认。
- 英语日历原本只圈三天；现在卡片可拖动，一周最终圈满七天。
- 弘大原本直接拍照；新增可调身高尺、188/178 对照和镜中踮脚互动，合影作为第一张胶片的实际成果。
- 海洋馆原本下载整个游戏画布；现在生成独立拍立得，构图维持最小间距，照片留存进入蒙太奇。
- 人生四格与黄发原本没有延续；照片成果存入第六格，后续章节沿用黄发造型。
- 宿舍告别原本在动作开始立即隐藏 Jenny；现在先走入门口、再淡出，Herry 留下看门，旁白期间收集按钮保持隐藏。
- 角色绘制顺序导致伙伴互相穿插；主要角色统一按地面深度排序，衣服跟随其所属角色。
- 普通操作反复弹长对白；英语卡片、选食物改为短反馈，让场景动作保持连续。
- 增加章节入场、呼吸提示、轻音效、统一光影、手机横竖屏布局与减少动画选项。

## 保留的个人细节

三章大衣仍是 Herry 带来给冷的 Jenny 穿，不是现场脱衣，也不是购入礼物。沃尔玛保留黑椒烤鸭、餐桌保留蛙来哒和老船长招牌；Hello Kitty、花生、身高差与不均匀黄发继续保留。
