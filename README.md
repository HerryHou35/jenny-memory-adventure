# Jenny 的生日回忆冒险

一个手机优先的像素回忆探索游戏：八个章节、跟随的花生、可重玩的放映室胶片墙，以及约 45 秒的回忆蒙太奇。

## 网站发布

- GitHub Pages：`https://HerryHou35.github.io/jenny-memory-adventure/`。
- Vercel 备用地址：`https://jenny-memory-adventure.vercel.app/`。
- 用户于 2026-10-18 同意将仓库公开。仓库中的代码、成品照片、视频、信件与历史提交均可被访问和下载；原始 `memory/`、`bgm/`、`彩蛋/` 仍只保留在本机，不额外上传。
- `.github/workflows/pages.yml` 在 main 更新时自动部署，也可在 Actions 中手动运行。仅发布 `dist/`，不安装依赖、不执行构建脚本、不使用个人访问令牌；官方 Actions 固定到核验过的提交。
- 项目页位于子路径，图片、媒体和脚本必须保持相对路径。GitHub Pages 与 Vercel 使用不同域名，浏览器存档不会自动互通。国内网络可达性需在实际设备上测试，不保证无代理稳定访问。

## 本地预览方式

直接打开 `dist/index.html`，或在仓库根目录启动任意静态文件服务器并将根目录指向 `dist/`。

## 替换素材

把素材放在 `dist/assets/`：

- `birthday-video.mp4`：最终生日视频，推荐 H.264 编码的 MP4。在 `dist/assets/ending.json` 把 `video` 设置为 `assets/birthday-video.mp4`。
- 已接入 `memory/1` 和 `memory/2` 共 59 张照片、2 段回忆视频；顺序记录在 `docs/MEMORY-PHOTO-ORDER.json`，配置为 `dist/assets/ending.json` 的 `media` 数组。先播指定首图，再按文件夹 1、2 自然排序，视频穿插其中且静音。
- 像素截图旋转交叠后淡至黑色，彻底黑屏 4 秒，再让首张真人照片以约 1.2 秒缓缓淡入，进入“漂浮回忆长带”：真人照片沿 S 形空间轨迹逐张入场，主照片大幅展示，旧照片旋转、缩小并退向侧后方。之后接生日字幕和视频，不使用网格照片墙。
- 时间线自动分配到钢琴曲的实际时长约 138 秒，每张照片至少 2 秒，视频分配更长展示时间；首尾加长，每张先停在中央，最后约三分之一时间才退向远处。使用音乐播放进度驱动动画，最后一张和音乐一起结束，再显示生日字幕。BGM 只播一次，不重新循环。
- 已接入用户提供的《昼夜 - 刻在我心底的名字（钢琴演奏版）》OGG，原件保留在 `bgm/`，网站使用 `dist/assets/birthday-bgm.ogg`。浏览器读取时长约 138 秒。`ending.json` 的 `bgm_volume` 为音量；真人照片开始时配乐渐入，关闭合成环境音，离开终章或进入真人视频时停止配乐。自动播放被阻止时出现“播放配乐”按钮。
- 像素小游戏和像素蒙太奇使用《LokLok Piano - 去北极忘记你（钢琴版）》，网站副本为 `dist/assets/pixel-bgm.ogg`。点击开始后渐入、跨章节连续循环，静音或切到后台时暂停。像素蒙太奇最后 4 秒淡出，黑屏阶段停止，之后才启动真人回忆钢琴曲，不叠播。返回小游戏恢复像素配乐。

后续照片可以按章节命名后加入，例如 `hongdae-01.jpg`、`aquarium-01.jpg`、`campus-01.jpg`。

游戏进度保存在浏览器的 `localStorage` 中。

## 操作与重玩

正式展示前，请在实际演出的设备、浏览器和网址上点击“提前准备全部素材”（约 90.6 MiB），等待全部校验完成后再开始。准备会保留原始成品字节、顺序和清晰度；失败或暂停可继续。开始前会再次检查完整缓存，不完整时不能开始。两站缓存互不通用，清理浏览数据、隐私模式或系统回收可能使缓存失效。

准备清单与缓存测试：运行 `node scripts/generate-precache.cjs` 获取清单更新补丁；任何 `dist` 运行时文件更新后须重新生成并应用。`node scripts/generate-precache.cjs --check` 只读校验清单，GitHub Pages 自动部署也会先执行此检查。运行 `node scripts/qa-prepare.cjs` 验证离线、失败、校验和版本隔离。

点击地面或使用 WASD/方向键移动，靠近物品后点击动作按钮。空格或 Enter 也可执行动作和推进对白。英语卡片可从左上角随身物品栏拖到右侧日历。放映室胶片墙上的已完成章节可单独重玩；右上角“重玩”需确认后才清除整段进度。“◌”可减少动画效果，“♪”关闭声音。

## 文件组织与验证

本地开发预览右上角提供“开发 · 跳到某一幕”，可直接进入各章、Herry 投篮、人生四格、站台送花、宿舍告别和终章蒙太奇。跳转不覆盖正常存档，正式网站不显示此菜单。弘大身高尺环节由 Herry 踮脚，花生正常站立，镜中倒影同步。

- `dist/app.js`：八章原有玩法与基础场景绘制。
- `dist/polish.js`：导演层、拖拽、存档恢复、胶片墙、蒙太奇与音效。
- `dist/polish.css`：统一的电影框架、开场、交互和手机布局。
- `scripts/qa-v19.cjs`：浏览器集成检查，覆盖八章、拖拽、告别、结尾、刷新和重玩。仅加速测试中的移动距离与等待动画，阶段推进使用游戏动作。

运行 `node --check dist/app.js`、`node --check dist/polish.js`，浏览器检查为 `node scripts/qa-v19.cjs`。本机测试脚本使用已安装的 Playwright 和 Chrome，截图位于忽略的 `.sites-runtime/qa`。
